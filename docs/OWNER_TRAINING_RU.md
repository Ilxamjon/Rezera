# Rezera — инструкция для владельца клуба (бета)

Короткий гайд для запуска бронирований в клубе через приложение Rezera.

## 1. Что умеет приложение

- Клиенты видят свободные ПК / залы и бронируют слот заранее
- Вы (или сотрудник) подтверждаете / отклоняете заявки
- Check-in по кнопке или QR на ресурсе
- Оплата **на месте** (в приложении оплаты нет)

## 2. Первый вход

1. Установите APK Rezera (ссылку даёт команда Rezera).
2. Зарегистрируйтесь по телефону Узбекистана (`+998…`).
3. В профиле откройте **Режим владельца** (после создания или привязки клуба).

## 3. Настройка клуба (один раз)

1. Создайте заведение (название, адрес, район Ташкента).
2. Заполните **часы работы** (ночные смены 12:00–06:00 поддерживаются).
3. Создайте **ресурсы** (PC-01, VIP-01…) с ценой за час в сумах.
4. Дождитесь **одобрения** платформой — только после этого клуб виден клиентам.
5. Режим подтверждения:
   - **Мгновенный** — бронь сразу подтверждена
   - **Вручную** — клиент ждёт вашего Confirm / Reject

## 4. Рабочий день

### Вкладка «Сегодня»
- Список броней на текущий день
- **Подтвердить / Отклонить** (если режим ручной)
- **Check-in** — гость пришёл
- **QR check-in** — отсканировать QR ресурса
- **Check-out** — сессия завершена
- **No-show** — гость не пришёл вовремя

### Ресурсы
- Добавляйте / редактируйте ПК
- **QR** — распечатайте и повесьте на монитор / стол

### Уведомления
- Колокольчик в приложении: новые брони и отмены

## 5. Правила, которые важно объяснить клиентам

- Бронь занимает ПК — параллельно тот же слот забронировать нельзя
- Pending-брони истекают, если их не подтвердить вовремя
- Отмена клиентом — по политике клуба (обычно за N минут до начала)
- Оплата — **только в клубе**, сумму видно в брони

## 6. Типичные проблемы

| Проблема | Что сделать |
|---|---|
| Клуб не виден в поиске | Проверьте одобрение / публикацию / онбординг |
| «Слот занят» | Выберите другое время или другой ПК |
| Нет связи с сервером | Wi‑Fi / VPN; сообщите команде Rezera |
| Сотрудник не видит Today | Добавьте его как staff в клуб |
